# Contributing to KITHÁRA NÉA

Thank you for your interest in KITHÁRA NÉA. Bug fixes, improvements, and suggestions are welcome.

## How to Contribute

You can open an issue to report a bug or suggest an improvement, fork the repository, modify the code, and submit a pull request.

To make contributions easier to review:

- Briefly explain what has changed and why.
- Where possible, keep each pull request focused on a single topic.
- Disclose any added third-party dependencies, resources, or licenses.
- Do not include any code, models, data, or resources that you are not authorized to redistribute.
- Describe any tests you have performed.
